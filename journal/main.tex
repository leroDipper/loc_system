% ABSTRACT
% ----------------------------------------------------------
\begin{abstract}
Indoor visual localisation is a critical component for mobile robotics and augmented reality applications in indoor environments. However, the widespread adoption of indoor localisation systems in settings such as warehouses, factories, and other large-scale indoor spaces is often hindered by the high computational demands of modern visual localisation techniques, which typically require powerful hardware to operate in real time. This paper presents a study on adapting state-of-the-art visual localisation methods for resource-constrained platforms, examining the trade-offs between accuracy, speed, and memory usage. We explore key design decisions including feature extraction methods, model optimization techniques, map representation strategies, and map querying approaches. The proposed methods are evaluated on a budget-friendly laptop and a Raspberry Pi 5. Our results demonstrate that real-time indoor visual localisation can be achieved using optimized learned feature extractors and efficient map querying techniques without significant loss in localisation accuracy. The pipeline implementation on the Pi 5 achieves an average localisation accuracy of 8 cm across three TUM indoor datasets at an average frame rate of 24 FPS and a memory footprint of 200 MB per frame. These results outperform traditional hand-crafted feature-based methods on the same hardware in terms of FPS and accuracy, demonstrate real-time implementation of deep learning-based feature extractors on CPU-only devices.
\end{abstract}

\textbf{Keywords:} Indoor Visual Localisation; Resource-Constrained Platforms; Feature Extraction; Neural Network Optimisation; Embedded Systems; Real-Time Performance
